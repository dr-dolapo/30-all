How it would ship

  • Three.js loads only when a profile's Tennis section scrolls into view, so the rest of the app stays as fast as now. It pauses when off-screen.
  • Vertical scrolling still works over the passport; only sideways drags turn pages.
  • Reduced motion: no sway or peek, the shot shows one still frame, pages snap quickly.
  • No WebGL: the four inside pages show as flat images.
  • Screen readers get the same details as text (home court, hand, backhand, racquet, favourite shot).
  • Racquet brands are written in our type, never their logos.
